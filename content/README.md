# CNOP

2026年五月，在秦博老师的怂恿下，我开始进行 AI4Science 方向的工作，具体场景是气象学，再具体一点就是 ENSO。

在当时的AI+气象领域，大家最热衷的事情，同时也是最大的难关，叫做“卷指标”。说得文雅一点，就是提高AI模型在气象数据上的预报技巧。由此引发了很多工作：数据同化、数据降尺度、模型架构创新……然而秦博老师对这些并不感兴趣，他热衷于更加纯粹的 AI4Science，准确而言，他只想做“Science”，只想解决科学问题。至于预报技巧——一群科学家为一项指标从92%提升到92.1%而兴奋的东西——并没有什么卵用。

我认可他的观念，同时也深受其影响。所以开始围绕CNOP，条件非线性最优扰动，做一系列工作。这些工作非常有趣，再加上秦博老师是一个率真且踏实的天才科学家，CNOP的研究变得异常简单且——这个词很贴切——“solid”。

CNOP 的方法，简单来说，就是将模型参数冻结，将原本在训练阶段作用在参数上的反向传播，迁移到推理阶段，并作用在输入上。由此，在一定的限制下，朝着想要的输出，对输入进行优化。我们用它寻找一个叫做optimal precursor，最优前期征兆的东西。

这个方法似乎在控制理论和不动点理论中都早有先例。但我还是想尽力澄清CNOP与它们不同，虽然以我现在的水平或许很难介绍清楚：

CNOP的应用场景是地球，地球有一条很重要的性质：无与伦比的自我调节能力。对于控制理论和不动点理论，它们的应用场景——LLM也好，机器人也好，其稳定性必然远远不如地球。所以不稳定不动点其实只是导致了单点的爆炸或坍缩——这在地球是不可能的。地球上使得未来发生剧变的事件，一定不是单点式的影响，而是造成了地球整体的混沌，地球的某一部分调节系统陷入了瘫痪，才导致了CNOP的传播，才导致了未来的剧变。不过这部分解释还是很模糊。
