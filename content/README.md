# CNOP

这是一个以 Markdown 为内容源的个人知识库。

你可以在 `content/` 下继续创建文件夹，并把 `.md` 文件放进去。文件夹会自动出现在左侧目录树中，每个 Markdown 文件都会生成一篇独立文档。

## 目录结构

```text
content/
├── README.md
├── guides/
│   └── writing.md
└── research/
    └── cnop.md
```

## 写作方式

每篇文档使用文件中的第一个一级标题作为页面标题。二级和三级标题会自动生成右侧目录。

支持普通 Markdown、列表、引用、代码块、链接、图片和基础 LaTeX 公式。
