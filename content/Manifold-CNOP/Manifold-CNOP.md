CNOP 要在幅度约束下找让预报目标 J 最大的初始扰动 δ。但欧氏空间里的幅度（RMS/能量）约束不保证扰动物理上真实——优化器完全可以在约束球内指向一个「不可能发生的地球状态」。地球状态的分布是一个高维空间中的流形，真实的 CNOP 应该保证扰动后的状态在该流形中游动，该流形可以通过一个 diffusion model 来拟合得到。我用 CMIP6 训了一个这样的 diffusion model，随后做了一系列实验。

### 新的优化架构

之前有过典型的将优化限制在流形上的做法：依旧在物理限制上优化，每优化一步，就利用diffusion model——加噪、去噪——拉回流形上。

但是这引入了一个问题：diffusion model这一步操作的梯度没有被传播到扰动上，所以这一步优化是片面的，优化器并不知道自己走完这一步之后，又会被如何拉扯。在大多数情况下，这样的优化策略无法到达CNOP。

因此，我们需要这样一种优化架构，可以让梯度完整地流经预测模型与扩散模型，让扰动在manifold上稳定优化——这有两种实现方法：
- 潜空间预测。流程为 x -> noise -> z_0 -> predict -> z -> denoise -> y。梯度完整地流经扩散模型的正反过程以及中间的潜空间预测模型，传导到x上，优化出CNOP。
- 潜空间扰动。流程为 x -> noise -> z_0 -> denoise -> predict -> y。梯度只流经预测模型和扩散模型的去噪过程，作用到潜空间，在潜空间优化出CNOP。

最终采用了第二种，原因有以下几点：
- 1.第一种方法梯度流经的部分更多，而且流经了两个随机过程（扩散模型的两个过程），很有可能不能稳定优化；
- 2.第一种方法是 Yann LeCun 式思想，是 JEPA 式思想，太肮脏了，太肮脏了；
- 3.第二种方法的难点在，由于这是一个去噪过程，具有很强的随机性，在潜空间的扰动可能无法被精确还原为物理空间的扰动——那就麻烦了，求出来的 CNOP 还原到物理空间后发现是多个模糊的扰动。但是采用 DDIM inversion 来加噪可以巧妙地避免这一问题，正如最上方第一张图所示，DDIM inversion + denoise 的还原偏差仅 0.1%——这意味着潜空间的 CNOP 可以被精确还原到物理空间。
